## 二、加载体验（loading）

- 私有页（cart/orders/address/checkout/pay）改为 setup 内 `useLazyAsyncData(唯一 key, loader)`，loader 内 `useRequestFetch()` 带 cookie → **首屏 SSR 直出 + 客户端导航不阻塞 + 骨架可见**；loader 返回可序列化快照，水合首帧与服务端分支一致。
- 骨架与真实内容形状对齐（补副标题、加购按钮、缩略图高度）；状态切换用 `<Transition name="fade">`。
- 购物车/结算/支付新增移动端 sticky 底栏（`lg:hidden` + safe-area + 容器底部留白），桌面保持右栏/原布局。
- 商品搜索页分页保留占位并 `:disabled`，不再"整块卸载再出现"。
- 订单筛选/收藏/购物车写操作加 latest-wins 防竞态（`composables/useLatestRequest.ts`）。

## 三、过渡 / 动效

- 全局：`nuxt.config` 配置 `pageTransition {name:'page', mode:'out-in'}`、`layoutTransition`、`experimental.viewTransition`；`app/router.options.ts` 接管滚动（返回到保存位置 / hash 让出导航高度 / 普通导航 instant / reduced-motion 全 instant）。
- CSS：`tailwind.css` 新增 `.page-*` / `.fade-*` / `.list-*` / `.skeleton`（shimmer）与 `--duration-fast/base/slow`、`--ease-standard` 动效 token；`prefers-reduced-motion` 下同时关闭 html 平滑滚动。
- 组件：图集主图改双层交叉淡入（不再 `:key` 重建、不再闪白）+ 预加载 + 失败兜底（新增 `ShopImage`）；购物车/收藏/地址/订单列表加 `TransitionGroup`；轮播加 `visibilitychange` 暂停、可见暂停/播放按钮、触摸滑动、手动切图重置相位、非当前 slide `inert`；移动抽屉与二级分类浮层修 hover/键盘可达性。
- 商品详情页 `definePageMeta({ viewTransition: true })`，浏览器支持时走原生过场（不支持自动降级）。

## 四、结构与配置

- 新增 `app/layouts/default.vue`（Header + main + Footer）与 `auth.vue`（无 Footer）；16 个页面不再各自手写 `<SiteFooter />`。
- 新增 `app/error.vue`：404/500 不再是 Nuxt 英文裸页，带品牌、状态码、回首页/重试。
- 主题单一真源：`app.config.ts` `primary: 'brand'`，`tailwind.css` 的 `--color-primary*` 改为 brand 别名（修复"品牌 / rose / 墨黑"三套 primary 并存）。
- 删除空转的 `fonts` 配置，并 `ui: { fonts: false }` 关闭 @nuxt/fonts —— 避免 @storefront-ui 的 `"Inter"` 触发 Google Fonts 解析（国内 dev 启动 10s 超时重试）。
- 依赖：移除 `daisyui`、`@storefront-ui/vue`、`@storefront-ui/shared`、`@nuxt/image`（零使用，且它把 sharp 打进产物：服务端产物 37.9MB → 14MB）；`@storefront-ui/tailwind-config` 移到 dependencies（构建期 import）；`nitro.compressPublicAssets` 开启 gzip/brotli（产物 34 个 .gz + 34 个 .br）。
- 类型：`OrderItemVO` 收敛到 `types/shop-order.ts`；`useProductDetail` 同步化。

## 八、图形验证码重设计（2026-10-18 追加）

**问题**：旧验证码是 105×35 白底 JPEG + 1px 灰边框 + 衬线黑字 + **200 条 2px 随机线段**（等于铺了一层灰噪点），
在 48px 高的圆角容器里被放大/裁切后，又糊又脏，与「珊瑚玫红 × 奶油白」的品牌语言完全脱节。

**后端**（`ck-server/.../system/util/RandImageUtil.java`）：
- 2 倍分辨率 **224×96 PNG**（前端按 112×48 显示，高分屏不糊；JPEG 会把文字边缘糊成毛边）；
- 奶油白渐变底 + 品牌色低透明度光斑；去掉边框（由前端圆角容器负责）；
- 字符改无衬线粗体、品牌深珊瑚色、逐字 ±9° 旋转 + 随机基线；
- 干扰从 200 条线段改为 2~3 条低透明度贝塞尔曲线 + 16 个浅色小点；
- 保留原有 `SecureRandom`、方法签名、错误兜底图（尺寸一致，失败时不会让登录流程 500）。

**前端**（`app/components/auth/EmailCodeFields.vue`）：
- 容器宽度 104→112px，与 224:96 严格同比例，`object-cover` 不再裁字符；
- 去掉「粉底框 + 图片边框」的框套框，改白底单层描边；
- 悬停/键盘聚焦时显示「换一张」蒙层（此前整张图都是刷新按钮，但没有任何可见提示）。

**验证**：`/api/captcha/<key>` 返回 `data:image/png`，解码后为 224×96；登录页图形验证码实际渲染 112×48、hover 提示可见、控制台 0 error；
后端重新打包（`mvn -o -pl jeecg-module-system/jeecg-system-start -am -DskipTests clean package`）并重启。
