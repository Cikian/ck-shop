## 四、已锁定的跨端契约（恢复时不得再改，否则三端对不上）

1. 采集信封：`POST /shop/analytics/track/events`，body `{ "events": [ {...} ] }`。
2. 事件字段 **snake_case**（event_name/session_id/visitor_id/org_code/store_id/product_id/page_path/device_type/ip/duration_ms/props…）；`event_time` 为 **epoch 毫秒**。
3. BFF 只传原始 `ip`；country/province/city 由 Java 经 GeoLite2 解析；`org_code/store_id` 由 Java 经请求头 `X-Store-Code` 解析（解析不到留空）。
4. 管理端返回字段 camelCase、金额 string、时间 `yyyy-MM-dd HH:mm:ss`。
5. **比率字段统一**：`*Rate`/`funnel.steps[].rate`/`bounceRate` 返回字符串「百分数数值、不带 %、保留 2 位」（如 "12.34" = 12.34%）。
6. 枚举：`dim_type` ∈ global/store/product/region/source/device/page；`event_name` 按契约 §4.1；`/region` 的 `level` ∈ country/province/city。
7. 管理端入参：storeId/startTime/endTime/granularity/dim/limit/level/pageNo/pageSize/eventName/keyword（以 shopAnalytics.ts 注释为准）。
8. 菜单组件路径：`ck/shop/analytics/{BigScreen,Dashboard,Detail}`；按钮权限 3 个。
9. 导出：Phase 1 无独立导出端点，`shop-analytics:export` 仅 gate 前端 CSV。
