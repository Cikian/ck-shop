# docs 目录索引

本目录是 **ck-shop 多店铺商城** 的接口契约 / 交付说明 / 验证记录 / 排查记录归档。
**所有文档都是历史证据，只增不改**：需要修正时请新建文档并在文末注明"本文取代 XXX"，不要覆盖旧结论。

> 维护约定
> 1. 新增文档后，请在本文件对应分组里补一行（链接 + 一句话说明）。
> 2. 不要在本目录放图片/设计稿：设计稿统一放仓库根目录 `design-references/`（已被 `.gitignore` 忽略，不入库）。
> 3. `docs/store-redesign/` 下的两份契约文档**被源码注释引用**（`nuxt-shop/app/pages/cart.vue`、
>    `nuxt-shop/app/components/SiteFooter.vue`、`nuxt-shop/server/api/promotions/active.get.ts`），
>    移动或改名必须同步这些注释，否则引用会失效。
